Description du scénario

  1. Création : le client crée une demande. L'API génère un code métier (SAV-YYYY-NNNNNN), enregistre l'intervention à l'état NOUVELLE et notifie le directeur.
  2. Affectation : le directeur consulte les nouvelles demandes et affecte un employé. L'état passe à AFFECTEE, l'action est journalisée et l'employé/client sont notifiés.
  3. Traitement : l'employé consulte ses affectations et passe l'intervention à l'état EN_COURS.
  4. Clôture : l'employé renseigne le rapport et le prix, l'état passe à TERMINEE, un PDF est généré et le client est notifié.
  5. Consultation : le client télécharge le rapport PDF de son intervention terminée.
