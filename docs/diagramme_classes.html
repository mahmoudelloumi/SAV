5. Décisions de Conception

Héritage JOINED — stratégie choisie pour Utilisateur → Client/Employe. Crée 3 tables (utilisateur, client, employe) avec clés étrangères : meilleur compromis normalisation/performance.
Séparation HistoriqueIntervention / JournalAudit — l'historique trace les changements métier d'une intervention (champ par champ), tandis que le journal d'audit est global et technique. Les deux sont complémentaires.
BigDecimal pour les prix — utilisé au lieu de Double pour éviter les erreurs d'arrondi en virgule flottante sur les montants financiers.
Le Directeur est un Employé — modélisé comme un Employe avec le rôle DIRECTEUR, ce qui simplifie le modèle tout en conservant la distinction via l'enum Role.
